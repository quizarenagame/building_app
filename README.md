# سامانه مدیریت ساختمان (Building App)

یک پروژه‌ی آغازین Flutter با رابط کاربری فارسی، چیدمان راست‌به‌چپ، داشبورد ساکن/مدیر، کارت‌های وضعیت، دسترسی‌های سریع و نوار پیمایش پایین.

## پیش‌نیازها
- Flutter SDK نصب‌شده و در `PATH`
- Android Studio/Android SDK برای ساخت نسخه‌ی اندروید

## اجرا
```bash
flutter pub get
flutter run
```

اجرای وب:
```bash
flutter run -d chrome
```

ساخت خروجی وب:
```bash
flutter build web
```

در این نسخه هیچ وابستگی ثالثی استفاده نشده است؛ ابزارهای Flutter هنگام اولین build ممکن است به SDKهای نصب‌شده روی دستگاه نیاز داشته باشند. برای اندروید، Flutter مقدار `flutter.sdk` را در فایل محلی `android/local.properties` تنظیم می‌کند؛ این فایل عمداً وارد مخزن/بسته نشده است.

## ساختار
- `lib/main.dart`: رابط کاربری داشبورد فارسی و RTL
- `android/`: پیکربندی پایه‌ی Gradle و ورودی Kotlin اندروید
- `web/`: نقطه‌ی ورود وب و مشخصات PWA
